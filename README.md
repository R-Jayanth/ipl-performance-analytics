# IPL Performance Analysis using Power BI

This project explores IPL match data using Power BI to understand team performance, player statistics and match trends.

## About the Project

The dashboard provides insights into batting, bowling, fielding, toss decisions and match venues. It uses charts, summary cards and filters to make the data easier to explore.

## Key Analysis

1. Team comparison based on sixes and fours
2. Top batsmen by runs and players with the most sixes
3. Top bowlers by wickets
4. Toss decisions and their relationship with match wins
5. Top venues by matches won
6. Leading fielders by dismissals
7. Distribution of matches across cities

## Tools Used

Microsoft Power BI, DAX, Data Visualization and Data Analysis.

## Dashboard

The dashboard screenshots are available in the `IPL performance_analytics.pdf` file in this repository.

## What I Learned

This project helped me understand the IPL dataset, break down the data into meaningful categories, and identify the key metrics needed for each visual. I created individual DAX measures to calculate and analyse these metrics, then used them to build an interactive Power BI dashboard that presents team and player performance, toss outcomes, and venue trends in a clear and simple way.
